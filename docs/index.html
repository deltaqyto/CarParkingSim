About APEX

APEX is a framework for training reinforcement learning agents on autonomous car navigation tasks, designed with modularity at its core.

We have applied APEX to train RL agents to drive simulated cars and park them at designated goals.

Physics-Based Simulation

Realistic car dynamics with accurate steering, acceleration, and collision detection for training environments.

Modular Plugin System

Flexible & powerful architecture supports custom environments, reward functions, stop conditions, and observation modules.

Advanced RL Training

TD3 reinforcement learning with parallel training and curriculum support for efficient and scalable model development. Optimised simulation achieves very high training performance.

Key Features

Comprehensive tools and capabilities for autonomous vehicle research and development

Vision-Based Perception

ResNet-powered collision avoidance using a simulated top down camera.

Curriculum Learning

Progressive difficulty training with customisable curricula for learning progression and agent development.

YOLO-Based Goal Seeking

YOLO based approach determines goal location from top-down camera to guide agent

Modular Environment

Modules can be composed to create custom environments, rewards, observations and stopping reasons.

High Speed Environment

Environment simulation can be run at scale and is optimised for performance, clocking ~30k steps per second.

Unified State System

Straightforward data access across all modules with a state dictionary for flexible development.

System Architecture

APEX implements a modular design with custom gym environments and specialised trainers

Modular Component System

Reward Functions

Stop Conditions

Observation Modules
